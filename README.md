## 「雨の中」

Nintendo Switch向けに開発した2D横スクロールアクションゲーム
* 個人制作
* 開発環境：Visual Studio・C＋＋・OpenGL
* 制作時間：約1ヶ月

## アピールポイント
* ジャイロセンサーを使う独特な操作方法とそれを活用できるレベルデザイン
* シェーダー、パーティカルなどで作る特別な雰囲気、処理落ちはない
* やや広めで連続したマップ、動的に読み込む
* SwitchとWindowsの両プラットフォームに対応
